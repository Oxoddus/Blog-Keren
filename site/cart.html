Keranjang Belanja

Tambah produk, lihat subtotal dan lanjut ke checkout QRIS atau COD. Semua teroptimasi untuk perangkat HP.

Fitur Keranjang

  • Tambah/ubah/hapus item secara langsung
  • Checkout QRIS otomatis dengan notifikasi konsumen
  • Metode COD untuk pesanan lokal
  • Integrasi dengan backend API `POST /api/cart` dan `GET /api/cart/:userId`

Alur Pembelian

  1. Pilih produk dari halaman toko
  2. Tambahkan ke keranjang
  3. Lanjutkan ke pembayaran QRIS atau pilih COD
  4. Terima notifikasi pembayaran dan status pengiriman

Kontrol Mobile

Keranjang ini dirancang untuk diakses dari HP, termasuk tombol cepat, informasi order, dan pencarian produk.
